# 🚀 Portfolio | Bhilal CHITOU

Bienvenue sur le dépôt de mon portfolio personnel. Ce projet est une application web moderne, interactive et responsive, conçue pour présenter mon parcours, mes compétences techniques, mes projets et mes certifications.

## ✨ Caractéristiques

- **Design Moderne & Immersif** : Une interface utilisateur soignée avec des animations fluides et un mode sombre/lumineux.
- **Multi-langue** : Support complet pour plusieurs langues via un contexte de traduction.
- **Architecture Modulaire** : Composants React structurés pour une maintenance facile.
- **Sections Incluses** :
  - **Hero** : Introduction percutante avec liens sociaux (GitHub, LinkedIn, Facebook).
  - **À propos** : Détails sur mon parcours et ma vision.
  - **Compétences (Skills)** : Visualisation de mes expertises techniques.
  - **Projets** : Galerie de mes réalisations avec descriptions et liens.
  - **Certifications** : Liste de mes accomplissements académiques et professionnels.
  - **Contact** : Formulaire et informations de contact direct.

## 🛠️ Stack Technique

- **Frontend** : [React](https://reactjs.org/) (Hooks, Context API)
- **Build Tool** : [Vite](https://vitejs.dev/) (HMR ultra-rapide)
- **Styling** : CSS3 avec variables pour le thème et animations personnalisées.
- **Icons** : Lucide React.
- **Linting** : ESLint.

## 🚀 Installation et Lancement

Pour lancer le projet localement :

1.  **Cloner le dépôt** :
    ```bash
    git clone https://github.com/7Bhil/Bhilal.git
    cd Bhilal
    ```

2.  **Installer les dépendances** :
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```
    L'application sera accessible sur `http://localhost:5173`.

4.  **Builder pour la production** :
    ```bash
    npm run build
    ```
